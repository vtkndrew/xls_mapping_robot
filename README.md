# Скрипт автоматического мэппинга проводок

## Описание
Скрипт выполняет автоматическое сопоставление (мэппинг) данных между двумя листами Excel-файла:
- **"Шаблон пров и атриб"** - эталонные данные с фильтрацией по признаку "ПАО"
- **"Проводки по СП анализ"** - данные для обработки

Скрипт создаёт перекрёстные ссылки между листами на основе совпадения счетов и символов ОФР.

## Требования

### Системные требования
- Python 3.7 или выше
- Библиотека `openpyxl`

### Установка зависимостей
```bash
pip install openpyxl
```

## Использование

### Запуск через командную строку
```bash
python new.py path/to/your/file.xlsx
```

### Запуск в интерактивном режиме
```bash
python new.py
```
При запуске без аргументов скрипт запросит путь к файлу.

## Структура входного файла

### Лист "Шаблон пров и атриб"
- **Заголовки:** строка 7
- **Данные:** строки 8 и далее
- **Обязательные столбцы:**
  - Признак плана счетов (ПАО/КИБ)
  - Номер счета по Дт
  - Символ ОФР Дт
  - Номер счета по Кт
  - Символ ОФР Кт
  - № Показа
  - Дт Мэпинг Робот
  - Кт Мэпинг Робот

### Лист "Проводки по СП анализ"
- **Заголовки:** строка 1
- **Данные:** строки 2 и далее
- **Обязательные столбцы:**
  - Дт (формат: счет_символОФР или счет)
  - Кт (формат: счет_символОФР или счет)
  - Номера строк развёрнутых проводок
  - Дт Мэпинг Робот
  - Кт Мэпинг Робот
  - СП Робот

## Алгоритм работы

### Этап 1: Обработка шаблона
1. Фильтрация строк по признаку "ПАО"
2. Нормализация счетов (удаление точек)
3. Валидация данных (только цифры)
4. Создание ключей сравнения

### Этап 2: Мэппинг Шаблон → Проводки
1. Обработка листа "Проводки по СП анализ"
2. Парсинг формата счет_символОФР
3. Сопоставление по ключам
4. Запись ссылок на ячейки проводок в шаблон

### Этап 3: Мэппинг Проводки → Шаблон
1. Для каждой строки проводок без развёрнутых:
   - Запись ссылок на ячейки счетов из шаблона
   - Запись значений "№ Показа" в столбец "СП Робот"

### Этап 4: Обработка развёрнутых проводок
1. Поиск строк с заполненным столбцом "Номера строк развёрнутых проводок"
2. Сбор ссылок из указанных строк
3. Объединение ссылок через запятую

## Формат ссылок

Все ссылки создаются в формате Excel:
```
='Название листа'!A1
```

Множественные ссылки разделяются запятой с пробелом:
```
='Проводки по СП анализ'!B10, ='Проводки по СП анализ'!B15, ='Проводки по СП анализ'!B23
```

## Валидация данных

### Лист "Шаблон пров и атриб"
- ✅ Допустимы только цифры и точки
- ✅ Пустые значения допустимы для символов ОФР
- ❌ Пустые значения недопустимы для счетов Дт/Кт

### Лист "Проводки по СП анализ"
- ✅ Формат: счет_символОФР или просто счет
- ✅ Допустимо 0 или 1 подчёркивание
- ❌ Более одного подчёркивания - ошибка
- ❌ Недопустимые символы - ошибка

## Обработка ошибок

Скрипт обрабатывает следующие ситуации:
- ❌ Файл не найден
- ❌ Отсутствует требуемый лист
- ❌ Отсутствует требуемый столбец
- ❌ Недопустимые символы в данных
- ❌ Неправильный формат данных

Все ошибки логируются в файл `errors.txt` с полным контекстом.

## Решение проблем

### Ошибка: "Модуль openpyxl не найден"
```bash
pip install openpyxl
```

### Ошибка: "Файл не найден"
Проверьте:
- Правильность пути к файлу
- Наличие прав доступа к файлу
- Что файл не открыт в Excel

### Ошибка: "Лист не найден"
Убедитесь, что файл содержит листы с точными названиями:
- "Шаблон пров и атриб"
- "Проводки по СП анализ"

### Ошибка: "Столбец не найден"
Проверьте наличие всех требуемых столбцов и точность их названий (без лишних пробелов).

## Техническая информация

### Архитектура
- **Модульная структура** - каждый этап в отдельной функции
- **Двойное открытие файла** - для чтения значений и сохранения формул
- **Словари для быстрого поиска** - O(1) время доступа к ключам

### Классы
- `ProcessLogger` - логирование ошибок и предупреждений
- `ProcessStatistics` - сбор метрик обработки

### Основные функции
- `normalize_template_value()` - нормализация данных шаблона
- `parse_provodki_account()` - парсинг счетов проводок
- `create_comparison_key()` - создание ключа сравнения
- `create_excel_reference()` - формирование ссылок Excel
- `process_template_sheet()` - обработка шаблона
- `process_provodki_sheet_stage1()` - обработка проводок
- `process_expanded_provodki()` - обработка развёрнутых проводок
- `write_results_to_excel()` - запись результатов
